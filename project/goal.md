# Goal

Run an Instagram account that reviews AI tools and productivity software for
general productivity/AI enthusiasts, and earn recurring affiliate commissions
when readers sign up for the tools it features.

## The one number

**Saves per post.** Instagram weights saves above likes when deciding who else
sees a post, and save-worthy reference content is exactly what "here's a tool
that does X" content should be. If saves per post is climbing, the account is
working.

## The number that gates it right now

**Reach.** As of 2026-09-18 the three published posts reached 1-2 accounts each
and earned 0 saves. Saves cannot be optimised while reach is ~2 -- there is no
audience to save anything. Until reach is consistently in the hundreds, the
real objective is distribution, not copy quality.

## What success looks like, in order

1. Reach per post consistently >100 (means the account is being distributed)
2. Saves per post consistently >5 (means the content is worth keeping)
3. Bio-link clicks (not yet instrumented -- no bio link exists yet)
4. Affiliate signups (not yet possible -- no affiliate programs joined)

## Out of scope for now

Paid promotion, video editing beyond what can be automated, and anything
requiring a human to write copy by hand each day.
